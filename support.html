使い方とお問い合わせ

公共工事の電子小黒板（改ざん検知・信憑性の確認）には対応していません。発注者が電子小黒板を求める工事には使えません。

1. 現場をつくる

はじめに工事名と施工者を入れて現場をつくります。現場ごとに、黒板の様式・工種と測点の候補・連番を持ちます。

2. 撮る

ホームの［撮る］で、黒板が写真の上に見えたまま撮ります。工種と測点は前の値が入っているので、違うときだけ候補から選びます。黒板は指で動かして、大きさも変えられます。はじめてのときにカメラの使用を許可してください。

3. あとから黒板

写真のライブラリから写真を選ぶと、黒板を入れて保存できます。撮影日時は、その写真の日時を使います。

4. 写真台帳の PDF

工種や撮った日で写真を選んで、A4 縦に 3 枚ずつ（左に写真・右に黒板の項目と備考）の台帳を作ります。共有・印刷・ファイル App に保存できます。

よくあるご質問

ファイル名の決まりは？

「撮影日時（年月日-時分秒）_工種_測点_連番3桁.jpg」です。工種と測点の空白は「_」に、ファイル名に使えない記号は外し、それぞれ 20 字までにします。空のときは「-」です。

公共工事に使えますか？

電子小黒板（改ざん検知・信憑性の確認）が求められる工事には使えません。提出の決まりは発注者に確かめてください。

Help & Contact

Kokubandori does not support Japan's electronic small blackboards for public works (tamper detection and authenticity checks). It cannot be used where the client requires them.

1. Create a site

Start by entering the project name and contractor. Each site keeps its own board layout, work type and station suggestions, and numbering.

2. Shoot

Tap Shoot on the home screen and take photos with the board shown over the image. Work type and station start from your last values; pick from suggestions when they change. Drag and resize the board with your finger. Allow camera access the first time.

3. Add a board later

Pick a photo from your library to add a board and save it. The photo's own date and time are used.

4. Photo ledger PDF

Choose photos by work type or shooting day to make an A4 portrait ledger with three photos per page (photo on the left, board fields and notes on the right). Share, print or save to the Files app.

FAQ

How are files named?

"date-time (yyyyMMdd-HHmmss)_worktype_station_3-digit number.jpg". Spaces in work type and station become "_", characters not allowed in file names are removed, and each is cut to 20 characters. Empty fields become "-".

Can I use it for public works?

Not where electronic small blackboards (tamper detection and authenticity checks) are required. Check submission rules with your client.
